## First Steps
Reading the documentation, ***

I've never used Node.js before, but learning to install and run the project was simple enough with the one line in the README.
However, the game code itself was harder to read. There were many one-liners and magic numbers, and although the function titles described the purpose of functions, I couldn't understand exactly what was happening inside each one.

I did a major refactor, not changing any functionality but making the code more modular and readable. This also split the source folder into subfolders.
