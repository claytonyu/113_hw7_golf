# Handoff Document by Clayton Yu upon Inheriting this Project

## First Steps
I first read the documentation, spec and progress file to get a sense of the project. I've never used Node.js before, but learning to install and run the project was simple enough with the one line in the README.

## Trouble with Reading the Code
However, the game code itself was harder to read. There were many one-liners and magic numbers, and although the function titles described the purpose of functions, I couldn't understand exactly what was happening inside each one.

## Acceptance Criteria
The acceptance criteria were clear enough to work on, but gave me flexibility to work more on the game as I saw fit.

## Refactor for Readability
I did a major refactor, not changing any functionality but splitting the code into multiple subfolders to make it more modular and readable. I'll concede that since I haven't written any Node.js code, I don't know what notational standards are.
